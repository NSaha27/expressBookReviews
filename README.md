# Express Book Reviews App (A RESTful API Project)

This is a Book Review REST API capable of handling book-related operations, user interactions, authentication and review management. This API has been successfully tested using both Postman and cURL.

### Key concepts and skills covered here...
- Node.js and Server-Side JavaScript
- Node.js modules, require / imports and npm
- Creating HTTP/Web servers with Node.js
- Asynchronous I/O and non-blocking programming
- Callback functions and callback-related challenges
- Promises and async/await
- JSON processing and HTTP requests
- Axios in Node.js/Express
- Express.js framework
- Routing and middleware
- HTTP methods and REST APIs
- CRUD operations
- API design and backend web services
- Authentication and Authorization
- Session management and JWT-based authentication
- Express best practices
- Testing APIs with Postman and command-line tools such as cURL


This project gave me an opportunity to apply backend concepts in a practical, portfolio-oriented application rather than learning them only theoretically.
